# English Platform: архитектура

## Решения
- **Стек**: чистые ES-модули без сборки и без npm-зависимостей (в среде разработки npm-реестр недоступен), типы через JSDoc. Деплой: GitHub Pages / Cloudflare Pages, просто статика (бесплатно).
- **Прогресс**: IndexedDB/localStorage на устройстве + экспорт/импорт JSON-бэкапа. Серверная синхронизация — следующий этап (Supabase), архитектура хранилища скрыта за интерфейсом `Storage`.
- **Озвучка**: Web Speech API (браузерный TTS), выбор en-GB/en-US, скорость, обработка отсутствия голоса. Честно: качество зависит от устройства.
- **Контент**: JSON в `content/<level>/`, проверка собственным валидатором схемы (scripts/validate-content.js).
- **SRS**: упрощённый FSRS-подобный алгоритм с отдельными счётчиками «узнавание» и «активное воспроизведение».
- **Режимы**: «Новый урок» и «Повторение» разделены по `lessonId`; слово попадает в повторение только после первого прохождения.

## Структура данных
Level → Module → Lesson → (Explanation, VocabItem[], Exercise[], Text, Dialogue).
Каждый элемент хранит levelId, lessonId, blockId.

## Карта курса (уровни и вехи)
Pre-A1: звуки, алфавит, to be, артикли, числа, приветствия (≈25 уроков)
A1: Present Simple, have, there is/are, can, Present Continuous (≈60)
A2: Past Simple, Future, сравнения, модальные (≈70)
B1: Perfect, условные 0/1/2, пассив, косвенная речь (≈80)
B2: сложные времена, условные 3/смешанные, герундий/инфинитив, фразовые (≈80)
C1: инверсия, нюансы модальности, регистр, коллокации (≈70)
C2: стилистика, идиомы, подтекст, академическое письмо (≈60)
Переход на уровень: ≥80% по лексике и грамматике, ≥70% по чтению и аудированию, письмо проверено по критериям.

## Порядок реализации
1. Ядро (интерфейс, движок, SRS, хранилище, TTS)
2. Контент Pre-A1
3. Тесты и деплой
4. Остальные уровни по этапам


## Статус реализации

Готово: Pre-A1, 11 уроков (алфавит, to be, артикли, множественное число, числа, время, притяжательные, this/that, знакомство), 106 слов, диалог, 3 отдельных текста, 2 письменных задания, контрольная по блоку, диктанты, тренировка слабых тем.

Не сделано: A1–C2, диагностический стартовый тест, раздел дополнительных материалов, личный словарь, закладки, серверная синхронизация, оценка речи.

Принцип зачёта: контрольная засчитывается, только если каждый навык достиг своего порога (слова и грамматика 80%, чтение и аудирование 70%) и выполнены письменные задания. Высокий результат по одному навыку не компенсирует провал другого.
